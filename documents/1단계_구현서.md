# 1단계 구현서: Linux와 C 실행 확인

## 목표

WSL2 또는 Linux 환경에서 C 파일 하나를 직접 컴파일하고 실행한다. 이 단계에서는 `fork()` 등 프로세스 기능을 구현하지 않고, Linux에서 C 프로그램을 빌드하고 실행하는 기본 흐름만 확인한다.

## 완료 기준

- WSL2 또는 Linux 터미널에서 C 프로그램을 컴파일할 수 있다.
- 생성한 실행 파일을 실행할 수 있다.
- 프로그램이 종료 코드 `0`으로 정상 종료함을 확인할 수 있다.
- 생성한 파일이 Linux용 ELF 실행 파일임을 확인할 수 있다.

## 1. WSL 배포판 확인 및 실행

PowerShell에서 다음 명령을 실행한다.

```powershell
wsl -l -v
wsl
```

Ubuntu 등 사용할 배포판이 설치되어 있지 않다면 다음 명령으로 설치한다.

```powershell
wsl --install -d Ubuntu
```

이후에는 반드시 WSL 터미널 안에서 다음 작업을 진행한다.

## 2. C 컴파일러 설치

WSL 터미널에서 다음 명령을 실행한다.

```bash
sudo apt update
sudo apt install -y build-essential
gcc --version
```

`gcc --version`이 컴파일러 버전을 출력하면 준비가 완료된 것이다.

## 3. 프로젝트 폴더로 이동

WSL에서는 Windows 프로젝트 폴더를 다음 경로로 열 수 있다.

```bash
cd /mnt/c/home/dolggul2/project/linux-subprocess
```

## 4. `hello.c` 작성

프로젝트 폴더에 `hello.c` 파일을 만들고 다음 내용을 작성한다.

```c
#include <stdio.h>

int main(void) {
    printf("Linux에서 C 프로그램이 실행되었습니다.\\n");
    return 0;
}
```

## 5. 컴파일 및 실행

다음 명령으로 경고를 표시하도록 설정하고 컴파일한다.

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g -o hello hello.c
```

생성된 프로그램을 실행하고 종료 코드를 확인한다.

```bash
./hello
echo $?
```

다음과 비슷한 결과가 나오면 정상이다.

```text
Linux에서 C 프로그램이 실행되었습니다.
0
```

`0`은 프로그램이 정상 종료했다는 뜻이다.

## 6. Linux 실행 파일 확인

다음 명령을 실행한다.

```bash
file hello
```

출력에 `ELF 64-bit`가 포함되어 있으면 Linux용 실행 파일이 만들어진 것이다.

## 기록할 내용

1단계를 마친 뒤에는 아래 내용을 간단히 기록한다.

- 사용한 환경: 예) WSL2 Ubuntu
- 사용한 컴파일 명령: `gcc -std=c17 -Wall -Wextra -Wpedantic -g -o hello hello.c`
- 실행 결과: 출력 문구와 종료 코드 `0`
- `file hello` 명령에서 ELF 실행 파일임을 확인했는지 여부
